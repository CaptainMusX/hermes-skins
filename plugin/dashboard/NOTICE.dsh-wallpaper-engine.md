The Hermes WebWallGL renderer page and the layer/pointer/pause lifecycle in
`src/engine/backdrop-manager.js` were adapted from this project. The local
version is reduced to the host-agnostic surface Hermes needs: signed project
sources, fit/fps/quality controls, pointer forwarding, media properties and an
explicit parent message channel. The full upstream implementation contains
additional DSH-specific glass, font, mascot, fx/parallax and pet-link modules
that are not part of this port.

Wallpaper Engine workshop assets are not redistributed.
