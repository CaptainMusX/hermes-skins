# Hermes 皮肤中心 (Hermes Skins)

> **Hermes Desktop 专属皮肤画廊与自定义壁纸/毛玻璃引擎**  
> 深度分析与复刻 [dsh-skins](https://github.com/zhu1090093659/dsh-skins) 的核心架构与换肤体验，为 **Hermes Desktop** 全新打造。

---

## 🌟 核心亮点

- 🖼️ **全格式自定义壁纸支持**：静态图片（JPG/PNG/WebP/GIF/SVG）、动态循环视频（MP4/WebM）、离线内置矢量艺术壁纸。
- 🔮 **通透毛玻璃质感 (Glassmorphism)**：接管 Hermes 桌面端的透光层，主会话视口、侧边栏、卡片均可呈现晶莹剔透的半透明磨砂质感。
- 🛡️ **智能防遮挡遮罩 (Occlusion Mask)**：提供 0%–100% 遮罩滑块，自适应暗色/亮色模式，确保任何复杂壁纸下，代码块与文字始终清晰易读。
- ✨ **原子级试穿（Try-on）与应用（Apply）**：点击任意皮肤即可无缝即时试穿预览；顶部悬浮条随时允许“一键应用”或“退出试穿还原原状”。
- 🎨 **6 款经典高品质内置皮肤**：
  - **蓝色幻想 (Blue Fantasy)**：巨鲸星海，长春花靛蓝与优雅半透明面板。
  - **鲸吟 (Whale Song)**：深海鲸语女神与冰蓝海洋冷色系。
  - **深海女仆工坊 (Abyssal Maid Atelier)**：香槟柔金与华丽宫廷风。
  - **霓虹赛博 2077 (Cyberpunk Neon)**：纯黑底色与电光青蓝、粉紫高光。
  - **黑曜翡翠 (Forest Obsidian)**：墨黑暗夜与松石翠绿，极致护眼。
  - **落樱浅风 (Sakura Breeze)**：雅致粉白明快浅色美学。
- 🛠️ **自定义主题工坊 (Theme Studio)**：自由调配专属色卡（Accent、Background、Foreground、Card），支持一键试穿、保存与导出 JSON。
- ⚡ **多入口无缝集成**：
  - 侧边栏专属导航图标（点击直接打开画廊）
  - 右下角状态栏挂件（点击弹出快捷微调面板）
  - 全局 ⌘K / Ctrl+K 命令面板搜索
