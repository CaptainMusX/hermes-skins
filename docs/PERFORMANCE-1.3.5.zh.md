# 1.3.5 GPU 占用修复与审查记录

日期：2026-10-04。对比基线为 GitHub `origin/main` 的 `7d7cd1e`，已通过远端查询核对。仓库原有未提交修改完整保留，并在开始修复前复制到 `verification/performance-before-20261004-180457/`；旧安装版单独保存为该目录下的 `installed-plugin.js`。

## 已确认的根因

本机旧安装版同时在 `renderFrame()` 和 `render()` 中调用 `requestAnimationFrame(render)`。一次刷新执行的每个回调会产生两个下一轮回调；它与已发布基线的单条调度链不同。使用旧安装文件实际内嵌脚本、虚拟刷新队列和 GL 调用记录器安全复现了 `2 → 4 → 8 → 16 → 32 → 64 → 128 → 256` 的增长，未让旧代码在真实 GPU 上重跑。

修复版由一个调度器管理唯一的 rAF/定时器句柄。等待清单、暂停、上下文丢失和退出时不轮询；恢复消息不会增加第二条链。背景绘制上限为 30 FPS，避免跟随高刷新率显示器继续增加负担。调度实现参考了 [WHATWG 动画帧规范](https://html.spec.whatwg.org/multipage/imagebitmap-and-animations.html#animation-frames)。

## 修复与第二轮优化

- 插件不再提取或渲染光标水面波纹，也不会消费旧清单中的波纹字段。保留蝴蝶 X-ray 替换纹理、靠近光标淡出、移开恢复，以及原有 shake 动画。场景本身的普通水面反射保留。
- 没有反射图层时跳过整场景的离屏绘制与 FBO 分配。
- 同一视频在同一渲染帧只上传一次；有解码帧计数时按解码帧去重。播放/暂停只在状态变化时触发，不在每个绘制分支重复调用。
- 缓存 uniform 和 attribute 地址，减少每帧重复的 WebGL 查询。
- 禁用 MSAA，声明低功耗偏好；画布最长边限制为 2560 像素。单张图片纹理限制为约 4 百万像素、最长边 4096，图片纹理总额限制为 128 MiB，超限时停止并退回静帧。这会降低超大壁纸纹理的细节，但保留布局和交互。
- 3D 单个粒子系统最多 256 个粒子，避免满载时积攒发射量后集中释放。
- 切换或禁用时中止旧清单加载，取消待发送的光标回调，暂停并卸载视频源，销毁旧场景上下文，再释放 Blob URLs。
- 绘制异常停止调度并通知宿主；同一壁纸最多自动重建一次，重复上下文故障退回已有静帧，避免无限重建。
- 设置遮罩和嵌套按钮不再叠加全屏模糊；对话框磨砂使用当前参数，0 时关闭。样式相同则不重写整份 CSS。
- 页面滚动恢复和终端重排的排队回调在退出时取消；网页资源的 64 MiB 上限不再被装饰资源的错误捕获吞掉，目录边界检查也已收紧。
