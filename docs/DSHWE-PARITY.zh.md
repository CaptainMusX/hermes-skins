# DSHWE 功能对齐台账

参考项目：[elysia395/dsh-wallpaper-engine](https://github.com/elysia395/dsh-wallpaper-engine)，对齐版本 1.4.2（`fd3e01fd11cd5ad83f46940ab4d61d971cfbcf91`）。

本表只记录壁纸引擎插件，不包含 DSH 宿主自身能力。皮肤画廊、主题工坊、试穿和主题注册已彻底移除。宠物、吉祥物、会话头像、pet-link 按用户要求不实现。

| 模块 | DSHWE 功能 | Hermes 状态 |
| --- | --- | --- |
| 入口 | 设置中的壁纸引擎页 | 设置 → 外观 → 常规底部入口卡；无侧栏入口 |
| 页面结构 | 壁纸库 / 外观 / 效果 / 声音 / 高级 / 扩展 / 关于 | 同构七页签；扩展页只保留 FX 与视差 |
| 壁纸类型 | Scene / Web / Video / Picture / 自定义图片 / 视频 | 全部接入；额外支持本地文件导入、URL 与 Bing 每日一图 |
| 壁纸库 | 搜索、内容分级、类型、方向、布局筛选 | 已接入内容分级、类型、方向、搜索与卡片布局 |
| 壁纸库 | 隐藏 / 恢复 / 轮播候选过滤 | 已接入，隐藏不改源文件 |
| 壁纸库 | 用户轮播组、逐组间隔/顺序/推进方式 | 已接入；顺序/随机；按间隔或视频播完推进 |
| 壁纸库 | 图内幻灯间隔覆盖 | `pictureSlideSeconds` 已接入 |
| 壁纸库 | `project.json → general.properties` 壁纸属性面板与热更新 | 已接入；按 wallpaper id 保存覆盖值，支持 bool/slider/combo/color/文本/文件类 |
| 切换 | 硬切 / 淡化 / 推移 / 擦除 / 光圈 / 缩放 / 条带 | 已接入，含方向与快/标准/慢 |
| Scene | WebWallGL 实时渲染、指针、首帧看门狗、自动画质 | 已接入 |
| Scene | 场景音轨与音量 | 已接入渲染页音量控制；宿主音频频谱桥未伪造 |
| Web | WE API shim、严格沙箱、独立媒体源 | 已接入 |
| 视频 | 循环、音量、倍速、隐藏/失焦/电池暂停 | 已接入；帧率转码属于宿主级 ffmpeg 能力，未伪造 |
| 画面 | 暗化、模糊、透明度、亮度、对比度、饱和度、镜像、自由取景 | 已接入 |
| 液态玻璃 | 全局材质、输入框、浮层、设置窗 | 已接入 |
| 液态玻璃 | 色彩/透明度/模糊/边框/高光/保真度 | 已接入 |
| 液态玻璃 | 明暗玻璃色、侧栏/标题栏/圆角 | 已接入 Hermes 结构面映射 |
| 字体集 | 新建/重命名/保存/删除/导入/导出、系统字体扫描 | 已接入，随完整配置预设一并迁移 |
| 字体 | 全局字族、角色字号/字重/字族、组件级字体 | 已接入 |
| 配色 | 文字色角色、深色单独设置、全局 UI 配色、光标色 | 已接入 |
| 主题 | 主题随壁纸取色 | 已接入为 Hermes 强调色跟随 |
| 扩展 | 点击波纹/火花/两者、彗尾/星尘、彩虹/自定义、混合模式 | 已接入 |
| 扩展 | 背景/会话/输入框/侧栏/用户气泡/插件前端视差 | 已接入；宠物/吉祥物挂件排除 |
| 声音 | 壁纸音轨、音量、Now Playing / 系统媒体集成 | 已接入；Windows GSMTC 尽力读取，不支持时显示降级状态 |
| 高级 | 浏览方式、省电、场景诊断、缓存、整套预设导入导出 | 已接入 |
| 系统 | 版本、上游 attribution、许可与致谢 | 已接入关于页 |
| 已排除 | 吉祥物、会话头像、pet-link、mascot-avatar | 按用户要求不实现 |
| 已移除 | 皮肤画廊、主题工坊、试穿、主题注册 | 不随插件提供 |

说明：Hermes 与 DSH 的 DOM、主题令牌和宿主媒体能力不同；本插件以 Hermes 原生结构面为落点，不复制 DSH 专属 CSS 模块哈希。不能由 Hermes 公开 SDK 可靠提供的宿主级能力（例如 ffmpeg 抽帧转码、跨平台系统音频频谱）不伪造成功状态，而是在面板或诊断中明确显示降级。
